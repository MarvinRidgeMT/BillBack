## 8. How fields are compared

Text is Unicode-normalized, case-folded and whitespace-collapsed before comparing. Money must match to the cent. Dates must be the same calendar day after parsing. Hospital names and addresses match if equal after normalization or if the fuzzy ratio (token sort) is ≥ 0.90; for addresses every number (street number, ZIP) must also be exactly the same. Account numbers: case and whitespace ignored, separators kept. % of the poverty line must match exactly. (Code: `eval/compare.py`, tests: `backend/tests/test_compare.py`.)
